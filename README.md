# Faculty Qualifications and Credentialing Portal Guide

The guide Bossier Parish Community College's academic deans, assistant deans, and program directors use to prepare and submit faculty qualification determinations in the Faculty Qualifications and Credentialing Portal (https://fqc.joebrownlee.com), and to follow each record through approval in Jotform. It is a static page with its screenshots. It stores nothing and sends nothing.

The screenshots show a sample record with invented names and L-numbers. `index.html` is built from the guide's source, kept by the Office of Academic Affairs with the Portal's source. Edit the source and rebuild rather than editing this file by hand.
